# AI Assessment Generator

## Description
A production-ready web application that allows students to upload an assessment PDF, analyzes it using Google Gemini AI, and generates comprehensive answers, diagrams, and programming code based on the actual assessment structure. The final output is a combined PDF with the original assessment followed by AI-generated answers.

## Architecture
- **Frontend**: React + Vite + TypeScript + Tailwind CSS (Deployed on Vercel)
- **Backend**: Python + FastAPI + Uvicorn (Deployed on Render)
- **AI Engine**: Google Gemini 1.5 Pro
- **Image Generation**: Pollinations.ai API

## Local Setup

### Backend
1. `cd backend`
2. `python -m venv .venv`
3. Activate the virtual environment (`.venv\Scripts\Activate.ps1` on Windows or `source .venv/bin/activate` on Linux)
4. `pip install -r requirements.txt`
5. Copy `.env.example` to `.env` and set `AI_API_KEY` (Your Gemini API key).
6. Run the server: `uvicorn app.main:app --host 0.0.0.0 --port 8000`

### Frontend
1. `cd frontend`
2. `npm install`
3. Create `.env.local` and add `VITE_API_URL=http://localhost:8000/api`
4. Run the dev server: `npm run dev`

## Deployment

### Vercel (Frontend)
Set the build command to `npm run build` and output directory to `dist`. Set the environment variable `VITE_API_URL` to your Render backend URL.

### Render (Backend)
Deploy using the provided `render.yaml` or connect your GitHub repository and set the start command to `uvicorn app.main:app --host 0.0.0.0 --port $PORT`. Ensure `AI_API_KEY` and `FRONTEND_URL` are set in the environment variables.

## API Documentation
The API documentation is automatically generated by FastAPI and can be accessed at `http://localhost:8000/docs` when running the backend locally.
